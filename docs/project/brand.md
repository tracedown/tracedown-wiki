# Name & Logo

The Tracedown **source code** is Apache 2.0 — use it, modify it, redistribute
it, build on it. The Tracedown **name and logo** (the eye-with-sparkline mark)
are different: they exist to identify this project, so they are trademarks of
the Tracedown project and are **not** covered by the Apache license. © Tracedown
contributors, all rights reserved.

## What's welcome, no permission needed

- Using the unmodified name or logo **to refer to Tracedown**: articles, talks,
  screenshots, package listings, links, "monitored with Tracedown" credits.
- Shipping the unmodified logo where it belongs — package repositories and
  distributions redistributing unmodified Tracedown, dashboards linking here.
- Descriptive statements of fact: "compatible with Tracedown", "built on
  Tracedown".

## What's not

- **Modified versions** of the logo, or the mark restyled into another
  identity.
- Using the name or logo **as the identity of your own product, service, or
  fork** — a fork is welcome under the Apache license, under its own name and
  mark.
- Anything implying the project endorses, certifies, or operates your offering
  when it doesn't.

Unsure whether a use is fine? It probably is if it refers to Tracedown and
would mislead nobody — but ask via the repository issues and we'll say so in
writing.
